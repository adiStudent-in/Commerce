Measures of Central Tendency — Mean

Statistics for Economics · Class 11 · Only Mean · Simple Revision

Mean in one line: Mean is the average value that represents the whole data in one number.

1. What is Mean?

Central Tendency means one central value that represents the full data. Arithmetic Mean = Total of all values divided by number of values. It uses all observations.

How to identify series: No frequency = Individual. Values + frequency = Discrete. Classes + frequency = Continuous.

2. Key Terms in Simple Words

Individual SeriesRaw values given separately. Example: 5, 10, 15.
Discrete SeriesValues with frequency. Example: marks 10, 20 with students 5, 3.
Continuous SeriesClass intervals with frequency. Example: 0–10, 10–20.
Mid-point m(Lower + Upper) / 2. Always find first in continuous series.
Assumed Mean AAny value taken to simplify. Best = middle value.
Step cCommon gap. Example 10, 20, 30 → c = 10. Or class size 0–10 → c = 10.
NNumber of values. In discrete and continuous, N = Sum of f.
Weighted MeanMean when some items are more important. Weight = W.

3. Individual Series — Only Values

Method 1 — Direct: Add and Divide

Step 1: Add all values = Sum X. Step 2: Count values = N. Step 3: Mean = Sum X / N.

Method 2 — Assumed Mean: For Big Numbers

Step 1: Pick A, middle value is best. Step 2: d = X − A for each value. Step 3: Add = Sum d. Step 4: Mean = A + Sum d / N. Answer is same from both methods.

Example: 5, 10, 15. Direct: 30 / 3 = 10. Assumed A = 10: d = −5, 0, +5, Sum d = 0, Mean = 10 + 0 = 10.

4. Discrete Series — Values + Frequency

Here N = Sum f. Example: X = 10, 20 with f = 5, 3 → N = 8.

Method 1 — Direct

Step 1: Multiply X × f = fX. Step 2: Add = Sum fX. Step 3: Mean = Sum fX / N.

Method 2 — Assumed Mean

Pick A. d = X − A. fd = f × d. Mean = A + Sum fd / N.

Method 3 — Step Deviation: Shortest

Use only when X values have equal gap. Gap = c. d′ = (X − A) / c. fd′ = f × d′. Mean = A + (Sum fd′ / N) × c.

Must remember: Multiply by c at the end. If you forget c, answer is wrong.

5. Continuous Series — Classes + Frequency

First step in all 3 methods: find m = (Lower + Upper) / 2. Example 0–10 → m = 5. After this, m works like X.

MethodSteps
DirectFind m → fm = f × m → Mean = Sum fm / N
Assumedd = m − A → fd = f × d → Mean = A + Sum fd / N
Stepd′ = (m − A) / c → fd′ = f × d′ → Mean = A + (Sum fd′ / N) × c
Note: For 10–19, 20–29 type inclusive classes, use m directly. No correction needed for mean. Step method needs equal class size.

6. Weighted Mean and Combined Mean

Weighted Mean — When Importance Differs

Step 1: WX = W × X. Step 2: Add = Sum WX, Add weights = Sum W. Step 3: Mean = Sum WX / Sum W.

Use when subjects have different credit, or goods have different quantity consumed.

Combined Mean — Two Groups Joined

Mean12 = (N1 × Mean1 + N2 × Mean2) / (N1 + N2). For 3 groups, add N3 × Mean3 on top and N3 below.

7. Correction, Properties, Merits

Correction of Wrong Mean

Step 1: Wrong Total = Wrong Mean × N. Step 2: Correct Total = Wrong Total − Wrong value + Correct value. Step 3: Correct Mean = Correct Total / N.

3 Properties — Remember

  1. Sum of deviations from mean is always zero.
  2. Mean is affected by every value and extreme values.
  3. Sum of squared deviations is minimum from mean.

Merits and Demerits

MeritsDemerits
Easy to calculate, uses all values, fixed definite value, allows further calculation, stable and comparableAffected by extremes, cannot be found by graph, absurd for quality data like honesty, may be 2.4 children which is not in data

9. Perfect Question for Each Method — Solved

Q1. Individual Direct: Marks of 5 students are 12, 15, 18, 20, 25. Find mean.

Sum X = 12 + 15 + 18 + 20 + 25 = 90. N = 5. Mean = 90 / 5 = 18.

Q2. Individual Assumed Mean: Values 48, 52, 55, 60, 65. Take A = 55.

d = X − A = −7, −3, 0, 5, 10. Sum d = 5. Mean = 55 + 5/5 = 56.

Q3. Discrete Direct: X = 10, 20, 30 and f = 2, 3, 5.

fX = 20, 60, 150. Sum fX = 230. N = 10. Mean = 230 / 10 = 23.

Q4. Discrete Assumed Mean: Same data. Take A = 20.

d = −10, 0, 10. fd = −20, 0, 50. Sum fd = 30. Mean = 20 + 30/10 = 23.

Q5. Discrete Step Deviation: Same data. A = 20, c = 10.

d′ = −1, 0, 1. fd′ = −2, 0, 5. Sum fd′ = 3. Mean = 20 + (3/10) × 10 = 23.

Q6. Continuous Direct: Classes 0–10, 10–20, 20–30 and f = 4, 6, 10.

m = 5, 15, 25. fm = 20, 90, 250. Sum fm = 360. N = 20. Mean = 360 / 20 = 18.

Q7. Continuous Assumed Mean: Same data. A = 15.

d = −10, 0, 10. fd = −40, 0, 100. Sum fd = 60. Mean = 15 + 60/20 = 18.

Q8. Continuous Step Deviation: Same data. A = 15, c = 10.

d′ = −1, 0, 1. fd′ = −4, 0, 10. Sum fd′ = 6. Mean = 15 + (6/20) × 10 = 18.

Q9. Weighted Mean: English 70 weight 2, Maths 80 weight 3, Economics 90 weight 5.

WX = 140, 240, 450. Sum WX = 830. Sum W = 10. Mean = 830 / 10 = 83.

Q10. Combined Mean: Class A N1 = 30 Mean1 = 40. Class B N2 = 20 Mean2 = 50.

Mean = (30×40 + 20×50) / 50 = (1200 + 1000) / 50 = 44.

Q11. Correction: Mean of 10 items was 25. Later 22 was found wrongly read in place of 12.

Wrong total = 25 × 10 = 250. Correct total = 250 − 22 + 12 = 240. Correct mean = 240 / 10 = 24.
Notice: Q3–Q5 give same answer 23. Q6–Q8 give same answer 18. All 3 methods give same mean. In exam you can use any one method.

  3. Find missing frequency if mean is given.
  4. Calculate weighted mean and combined mean with example.
  5. Explain merits and demerits of mean. When is mean the best average?
