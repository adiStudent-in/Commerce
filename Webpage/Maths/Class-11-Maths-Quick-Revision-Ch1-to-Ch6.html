Chapter 1 · Sets — “Collection Ka Khel”

Set matlab well-defined collection — matlab ye crystal clear ho ki kaun andar hai, kaun bahar. “Good boys ka set” set nahi hai (good ka matlab sabke liye alag). “Vowels ka set {a,e,i,o,u}” set hai.

1. Do Tarike Se Likho

  • Roster (list): A = {1, 2, 3, 4} — order matter nahi karta, repeat likhna bekaar.
  • Set-builder: A = {x : x < 5, x ∈ N} — “aisi x jo…” wala style.

💡 Trick — De Morgan (pakka aayega): complement bahar aaye to sign palat jata hai. (A ∪ B)′ = A′ ∩ B′ · (A ∩ B)′ = A′ ∪ B′. “Bahar wala andar, ∪ bana ∩.” Aur A − B = A ∩ B′ — difference ko intersection me badal lo, sawal easy.

5. Counting Formulas — Venn wale sawal isi se

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)   ← overlap ek baar minus (do baar gin liya tha)
Only A = n(A) − n(A ∩ B)                ← "sirf" matlab lens hata do
Neither = n(U) − n(A ∪ B)               ← kul me se "kam-se-kam ek" ghata do
n(A ∪ B ∪ C) = (singles ka jod) − (pairs ka jod) + (teeno)
60-sec example — khud karo, phir dekho

60 students: 25 cricket, 20 football, 10 dono. Kam-se-kam ek? Koi nahi? Sirf cricket?

  1. Formula likho: n(C∪F) = 25 + 20 − 10 = 35 (kam-se-kam ek).
  2. Neither = 60 − 35 = 25.
  3. Only cricket = 25 − 10 = 15 (apne total me se overlap hatao).
✅ Answers: 35 / 25 / 15. Logic: “dono” do baar gina gaya, isliye ek baar minus.
🪤 Trap: A − B ≠ B − A (order matters!) · ∅ ≠ {0} ≠ {∅} — pehle me 0 elements, baaki dono me 1-1 element · complement hamesha U poochta hai, U diye bina A′ adhura hai.

Chapter 2 · Relations & Functions — “Pairing Ka Rule”

Relation matlab rishta jodna (x se y), function matlab pakka ek-loyal rishta — har x ka exactly ek y. Ek x ke do y = dhokha = function nahi.

1. Cartesian Product A × B

  • A × B = saare ordered pairs (a, b) — pehla A se, doosra B se. Order matters: (1,3) ≠ (3,1), isliye A × B ≠ B × A (aam taur pe).
  • n(A × B) = n(A) × n(B). Count poochhe to list mat banao — guna kar do.
  • (a, b) = (c, d) tabhi jab a = c aur b = d.

2. Relation vs Function — sabse confused point

💡 Trick — 3-second function test: x-values me koi repeat? Repeat mila + y alag = not a function. Graph me vertical line do baar kaate = not a function. “Har function relation hai, har relation function nahi.”

4. Graphs — aankhon se yaad karo (exam me sketch bhi poochhte hain)

Har graph ke neeche shape + range-trick ek line me. Pehle shape dekho, phir caption padho — photo-memory ban jayegi.

1. Constant f(x) = c Seedhi horizontal line. x kuch bhi ho, answer hamesha c ⇒ Range = {c}.
2. Identity f(x) = x Origin se 45° line. Jo x, wahi y ⇒ Domain = Range = R.
3. Polynomial f(x) = x² U-shape (parabola), vertex origin pe. Neeche kabhi nahi jata ⇒ Range [0, ∞).
4. Rational f(x) = 1/x Do tukde (Q1 + Q3). Axes ko chhoota nahi — wahi asymptotes. x = 0 allowed nahi.
5. Modulus f(x) = |x| V-shape, vertex origin. Negative output kabhi nahi ⇒ Range [0, ∞).
6. Signum f(x) = −1 / 0 / 1 Sirf 3 levels: −1, 0, 1. Hollow ○ = point included nahi ⇒ Range {−1, 0, 1}.
7. Greatest integer f(x) = [x] Seedhiyaan (steps). Left ● included, right ○ excluded. [1.2] = 1, [−0.3] = −1.
💡 Trick — Vertical line test (graph se function pehchano): khadi (vertical) line graph ko 2 jagah kaate = function NAHI. Circle ✘ fail, lekin line, V-shape, parabola, seedhiyaan ✔ pass. Aur dhyaan do — x² wala parabola function HAI (ek x pe ek y), bas one-one nahi hai.
💡 Trick — Domain ke 2 danger spots: (1) denominator ≠ 0 (2) root ke andar ≥ 0. Bas ye do check karo, domain nikal jayega. Range ke liye y = f(x) maan ke x nikalo — jo y fas jaaye wahi range se bahar.
60-sec examples
  1. f(x) = (2x+1)/(x−3): x = 3 pe denominator 0 ⇒ Domain = R − {3}. y se x nikalo: x = (3y+1)/(y−2) ⇒ y = 2 fase ⇒ Range = R − {2}.
  2. g(x) = √(x+5): andar ≥ 0 ⇒ x ≥ −5 ⇒ Domain [−5, ∞), root kabhi negative nahi ⇒ Range [0, ∞).
  3. [−1.2] = ? −1 nahi — −2 (−1.2 se chhota sabse bada integer). Yehi puchte hain!
🪤 Trap: Range ⊆ Codomain hota hai (barabar zaroori nahi) · [x] me negative decimals ulta girte hain ([−0.3] = −1!) · rational me wo x mat lo jo denominator zero kare.

Chapter 3 · Trigonometric Functions — “Sabse Bada, Sabse Scoring”

Trig me ratta + pattern dono chahiye. Pehle values table pakki karo, phir sign (ASTC), phir formulas. Aadhe sawal sirf 75° = 45°+30° jaise split se bante hain.

1. Degree ↔ Radian (ek hi bridge)

π radians = 180°   →   rad = deg × π/180  ·  deg = rad × 180/π
Yaad rakho: 30°=π/6 · 45°=π/4 · 60°=π/3 · 90°=π/2 · 180°=π · 270°=3π/2 · 360°=2π
Arc length: l = rθ   (θ hamesha radians me!)

2. Values Table — ye likhe bina paper mat do

Angle0°30°45°60°90°
sin01/21/√2√3/21

💡 Trick — sin wali line yaad karo (0, 1/2, 1/√2, √3/2, 1), cos uska ulta. tan = sin/cos. 90° pe tan/sec undefined — ye 1-mark me puchte hain.

3. Signs — ASTC (“Add Sugar To Coffee”)

QuadrantKaun PositiveYaad
QI (0–90°)All +Add
QII (90–180°)sin, cosecSugar
QIII (180–270°)tan, cotTo
QIV (270–360°)cos, secCoffee
  • 3 basic identities: sin²x + cos²x = 1 · 1 + tan²x = sec²x · 1 + cot²x = cosec²x.
  • Allied shortcut: 90°/270° pe function badalta hai (sin↔cos, tan↔cot, sec↔cosec); 180°/360° pe same rehta hai. Sign ASTC se lagao. Example: sin(180°−θ) = +sin θ; cos(90°+θ) = −sin θ.

4. Compound Angles (A±B wale)

sin(A+B) = sinAcosB + cosAsinB      sin(A−B) = sinAcosB − cosAsinB
cos(A+B) = cosAcosB − sinAsinB      cos(A−B) = cosAcosB + sinAsinB
tan(A+B) = (tanA + tanB)/(1 − tanA·tanB)
tan(A−B) = (tanA − tanB)/(1 + tanA·tanB)
💡 Trick: sin me sign same rehta (B wala), cos me ulta (+ wala − ban jata). tan me upar same, neeche ulta. 75° = 45°+30°, 15° = 45°−30° — split dekhte hi ye formulas lagao. sin 75° = (√6+√2)/4 — itna to direct yaad rakho.

5. Transformation (Sum ↔ Product)

sinC + sinD = 2 sin((C+D)/2) cos((C−D)/2)
sinC − sinD = 2 cos((C+D)/2) sin((C−D)/2)
cosC + cosD = 2 cos((C+D)/2) cos((C−D)/2)
cosC − cosD = −2 sin((C+D)/2) sin((C−D)/2)
2sinAcosB = sin(A+B)+sin(A−B) · 2cosAcosB = cos(A+B)+cos(A−B) · 2sinAsinB = cos(A−B)−cos(A+B)

6. Double / Triple Angle

sin2x = 2sinxcosx = 2tanx/(1+tan²x)
cos2x = cos²x−sin²x = 1−2sin²x = 2cos²x−1 = (1−tan²x)/(1+tan²x)
tan2x = 2tanx/(1−tan²x)
sin3x = 3sinx − 4sin³x  ·  cos3x = 4cos³x − 3cosx  ·  tan3x = (3tanx−tan³x)/(1−3tan²x)
60-sec examples (repeat hote hain)
  1. sin x = 3/5, QII ⇒ cos²x = 1−9/25 = 16/25, QII me cos negative ⇒ cos x = −4/5, tan x = −3/4, sin2x = 2·(3/5)·(−4/5) = −24/25.
  2. (sin x + sin 3x)/(cos x + cos 3x): upar = 2sin2xcosx, neeche = 2cos2xcosx ⇒ kaat do ⇒ tan2x. (C+D pattern dikhe to product banao.)
  3. cos4x = 1 − 8sin²xcos²x: 4x = 2×2x ⇒ 1−2sin²2x ⇒ sin2x = 2sinxcosx rakh do ⇒ proof done.
🪤 Trap: sin2x ≠ 2sinx! · cos ke 3 roop me se sawal ke hisaab se chuno · QII me cos/tan negative bhoolna = aadhe number gaye · π = 180° (π = 22/7 nahi yahan).

Chapter 4 · Complex Numbers — “i Ka Jaadu”

Jab x² = −1 ka jawab real me na mile, to maths ne i = √(−1) bana diya. Bas i² = −1 yaad rakho — poora chapter isi ek line pe khada hai.

1. Powers of i — remainder wala khel

i¹ = i · i² = −1 · i³ = −i · i⁴ = 1 → phir repeat (cycle of 4)
Trick: exponent ÷ 4 karo, sirf REMAINDER dekho.
i²⁷ → 27÷4 remainder 3 → i³ = −i  ·  i³² → remainder 0 → 1  ·  i⁴⁵ → remainder 1 → i
Example: i²⁷ + i³² − i⁴⁵ = (−i) + 1 − (i) = 1 − 2i

2. a + ib — jod, guna, bhaag

  • Form: z = a + ib (a = real part, b = imaginary part). a + ib = c + id ⇔ a = c aur b = d.
  • Multiply: normal kholo, i² = −1 rakh do. (a+ib)(c+id) = (ac−bd) + i(ad+bc).
  • Divide: upar-neeche conjugate se guna karo. Example: (3+2i)/(2−3i) → (2+3i) se guna → 13i/13 = i.
  • Equality: (2x+3) + i(y−1) = 7 + 4i ⇒ 2x+3 = 7 ⇒ x = 2; y−1 = 4 ⇒ y = 5.

3. Conjugate & Modulus — pakke 5 marks

💡 Trick — (a−ib)(a+ib) = a² + b² hamesha. Isliye division me conjugate se guna karte hi neeche real number ban jata hai. Aur 1/i = −i (kyunki i·(−i) = 1).
🪤 Trap (pakka puchte hain): √(−3)·√(−2) = −√6, √6 nahi! (i√3 · i√2 = i²√6 = −√6). Negative roots ko seedha guna mat karo — pehle i bahar nikalo. Aur |2−3i| = √13, √(4−9) = √(−5) bilkul nahi — squares me minus khatam.

Chapter 5 · Linear Inequalities — “Sign Paltu Chapter”

Equation me = hota hai, inequality me < > ≤ ≥. Ek hi golden rule hai — negative se guna/bhaag karo to sign palat jata hai. Bas ye yaad, chapter khatam.

1. Golden Rules

  • Jod-ghatao: dono taraf same number add/subtract — sign same.
  • Positive se guna/bhaag: sign same. Negative se: sign palat (< ↔ >, ≤ ↔ ≥).
  • Brackets: < > ⇒ ( ) open ○ · ≤ ≥ ⇒ [ ] closed ●.
  • System (do inequalities): dono alag solve karo, phir overlap (intersection) lo — “AND matlab common”.
60-sec examples
  1. −3x + 5 < 2(x−4) + 7 ⇒ −3x+5 < 2x−1 ⇒ −5x < −6 ⇒ −5 se bhaag + palto ⇒ x > 6/5 ⇒ (6/5, ∞), 6/5 pe ○, right shade.
  2. System: 3x−7 < 5+x AND 11−5x ≤ 1 ⇒ x < 6 aur x ≥ 2 ⇒ overlap = [2, 6).
  3. Marks wala (pakka pattern): 58, 62, 55, 4th = x, average ≥ 60 ⇒ (175+x)/4 ≥ 60 ⇒ 175+x ≥ 240 ⇒ x ≥ 65. “At least” = ≥, “at most” = ≤.
💡 Trick — Word problem ka template: “jo poochha use x maano → average/total ka expression banao → at least/at most ko ≥/≤ me badlo → solve.” Number line hamesha banao — open/closed ka 1 mark wahi milta hai.
🪤 Trap: −5x < −6 me sign palatna bhoolna = poora sawal zero · system me UNION (jod) nahi, INTERSECTION (common) lena hai · (2,6) vs [2,6) — bracket galat to mark gaya.

Chapter 6 · Permutations & Combinations — “Gin-ti Ka Game”

Sirf ek sawal poochho — “reshuffle karne se naya outcome banega?” Haan → P (order matters), Nahi → C (selection only). Arrangement/number/password/seat → P · Team/committee/group → C.

1. Formulas — 4 lines me poora chapter

n! = n×(n−1)×…×2×1 · 0! = 1 · 1! = 1
ⁿPᵣ = n!/(n−r)! = n(n−1)…(n−r+1)   ← arrangement, order matters
ⁿCᵣ = n!/(r!(n−r)!) = ⁿPᵣ/r!       ← selection, order no matter
Relation: ⁿPᵣ = r! × ⁿCᵣ  ·  ⁿCᵣ = ⁿCₙ₋ᵣ  ·  ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ
ⁿCᵣ = ⁿCₛ ⇒ r = s  YA  r + s = n   ← ye property direct number deti hai

2. Situation-wise Hathiyaar (table rat lo)

SituationKya KaroExample

60-sec examples (exam repeats)
  1. ⁿP₅ = 20 × ⁿP₃ ⇒ cancel n(n−1)(n−2) ⇒ (n−3)(n−4) = 20 ⇒ n²−7n−8 = 0 ⇒ (n−8)(n+1) = 0 ⇒ n = 8. (Pehle cancel, phir expand — factorials mat kholo.)
  2. ⁿC₈ = ⁿC₆ ⇒ 8+6 = n ⇒ n = 14, ¹⁴C₂ = 14×13/2 = 91.
  3. 6M+4W se 4 ki committee, kam-se-kam 2W: (2W2M) 6×15=90 + (3W1M) 4×6=24 + (4W) 1×1=1 ⇒ 115. AND = guna, OR (cases) = jod.
💡 Trick — 3 golden lines: (1) “Condition wala dabba pehle bharo.” (2) “ⁿP equation me common part pehle kaato.” (3) “Committee me groups ke beech ×, cases ke beech +.”
🪤 Trap: Committee/team me P lagana (C lagega!) · 0! = 1 bhoolna (0 nahi!) · “together” me andar ki arrangement (3!) guna karna bhoolna · repetition allowed vs not allowed padhe bina shuru karna.
